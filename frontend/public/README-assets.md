# PWA assets

- **Background image**: Add your app background as `bg.jpg` here (or `bg.png` and update the `background-image` url in `src/index.css`). It will appear behind all content with a dark overlay for readability.
- **Icons**: `pwa-512x512.png` is used for the PWA and Apple touch icon. Optional: add `pwa-192x192.png` for a sharper 192px icon; otherwise the 512px image is used for both sizes.
- **Favicon**: `favicon.svg` is the browser tab icon.
